# Caesar_Bot 👑 — Ichancy100 Telegram Bot

بوت تيليجرام متكامل لإدارة عمليات iChancy، يشمل:

- إنشاء وربط حسابات iChancy.
- إيداع وسحب رصيد البوت.
- شحن وسحب رصيد اللعبة.
- لوحة أدمن متقدمة.
- بونصات وعروض على طرق الإيداع.
- نظام إحالات متدرج.
- أكواد هدايا من المشرف.
- إهداء رصيد بين اللاعبين.
- Mini App Dashboard.
- قاعدة بيانات PostgreSQL عبر Neon.
- تشغيل على Render Web Service بنظام Webhook.

---

## أهم الميزات

### 1. إدارة المستخدمين

- تسجيل المستخدمين تلقائياً.
- قبول الشروط والأحكام.
- عرض رصيد البوت ورصيد اللعبة.
- سجل معاملات المستخدم.
- حذف الحساب من واجهة المستخدم.

---

### 2. iChancy

- إنشاء حساب iChancy تلقائياً.
- جلب Player ID.
- جلب رصيد اللاعب.
- شحن حساب اللعبة من رصيد البوت.
- سحب من حساب اللعبة إلى رصيد البوت.
- تجديد جلسة الوكيل تلقائياً عبر بيانات `AGENT_USERNAME` و `AGENT_PASSWORD`.

---

### 3. الإيداع والسحب

يدعم الإيداع والسحب عبر:

- Syriatel Cash
- MTN Cash
- Sham Cash SYP
- Sham Cash USD
- USDT TRC20
- USDT BEP20

#### منطق الدولار

- إيداع USD يستخدم سعر الشراء الأقل من لوحة الأدمن.
- سحب USD يستخدم سعر البيع الأعلى من لوحة الأدمن.
- الأسعار تُخزن في قاعدة البيانات وتُعدل من لوحة التحكم.

---

### 4. البونصات والعروض

المشرف يستطيع إنشاء عروض بونص على طرق الإيداع من لوحة التحكم.

يدعم العرض:

- اسم العرض.
- نسبة البونص.
- طريقة إيداع محددة أو كل الطرق.
- حد أدنى للإيداع.
- حد أعلى لقيمة البونص.
- إيقاف/تفعيل العرض.

عند قبول الإيداع، يطبق البوت أفضل عرض مطابق فقط، أي أعلى قيمة بونص إذا انطبق أكثر من عرض.

---

### 5. الإحالات

نظام إحالات متدرج:

```text
3 إحالات نشطة = 3%
5 إحالات نشطة = 5%
10 إحالات نشطة = 10%
```

- الإحالة تُسجل عند دخول مستخدم جديد من رابط الإحالة.
- الإحالة تصبح نشطة عند أول إيداع مقبول للمدعو.
- العمولة تُحسب على مبلغ الإيداع الأساسي فقط، بدون البونص.
- العمولة تُضاف فوراً إلى رصيد صاحب الإحالة.
- يوجد زر في لوحة المشرف لتفعيل أو إيقاف الإحالات.

---

### 6. أكواد الهدايا وإهداء الرصيد

#### كود هدية من المشرف

من لوحة الأدمن يمكن إنشاء كود بصيغة:

```text
CAESAR-BOT-XXXXXXXX
```

- لا يخصم من رصيد المشرف.
- يستخدم مرة واحدة.
- المستخدم يسترده من زر كود الهدية.

#### إهداء رصيد بين اللاعبين

المستخدم يستطيع إنشاء كود من رصيده بصيغة:

```text
CAESAR-XXXXXXXX
```

- يتم خصم القيمة من رصيد المُرسل.
- يستطيع لاعب آخر استرداد الكود.
- إنشاء واسترداد الأكواد محمي بعمليات قاعدة بيانات ذرية.

---

### 7. لوحة الأدمن

يدعم `/admin`:

- إحصائيات عامة.
- أسعار الصرف.
- عمولة السحب.
- تحديث كوكيز/جلسة iChancy.
- رصيد محفظة الوكيل.
- إدارة المستخدمين.
- إنشاء أكواد هدايا.
- إدارة البونصات والعروض.
- تفعيل/إيقاف الإحالات.
- قبول/رفض الإيداعات والسحوبات.

## التشغيل المحلي

1. أنشئ ملف `.env` من `env.example`.
2. ضع القيم الحقيقية.
3. ثبّت المتطلبات:

```bash
pip install -r requirements.txt
```

4. شغل البوت:

```bash
python telegram_bot/main.py
```

ملاحظة: التشغيل الحالي مبني على Webhook/Web Service، لذلك الاختبار الكامل يحتاج رابطاً عاماً مثل Render.

---

## النشر على Render

راجع الملف:

```text
DEPLOY_RENDER.md
```

المختصر:

```text
New + > Web Service
Build Command: pip install -r requirements.txt
Start Command: python telegram_bot/main.py
```

وأضف متغير:

```env
RENDER_EXTERNAL_URL=https://your-service-name.onrender.com
```

- referrals
- referral_commissions
- transactions
- gifts
- bot_settings
- bonus_rules
- pending_rejections

## ملاحظات تشغيل مهمة

- لا تعتمد على ملفات محلية لحفظ بيانات المستخدمين.
- كل البيانات المهمة محفوظة في PostgreSQL.
- أسعار الصرف تُدار من لوحة الأدمن وليس من `.env`.
- البونصات والإحالات تُخزن في قاعدة البيانات.
- أي تعديل على ملفات Python يحتاج Deploy جديد.
- تعديل ملفات التوثيق فقط لا يحتاج Deploy.
